# 数据工程

模型首先学习数据分布。数据流水线的目标不是“抓得越多越好”，而是在来源、质量、覆盖、法律边界、污染风险和计算预算之间建立可审计的选择。

## 端到端流水线

1. **来源登记**：记录数据集、许可、时间范围、语言、领域和采集方式。
2. **解析与规范化**：保留文档边界、结构和必要元数据，避免把模板噪声变成正文。
3. **质量过滤**：规则、分类器与模型评分需要分别校准，不能只看通过率。
4. **去重**：文档级、段落级和近似去重影响记忆、泛化与 benchmark 污染。
5. **安全与隐私处理**：识别个人数据、凭据、恶意内容和需要删除的来源。
6. **配比与采样**：按语言、领域、质量和难度设置权重，控制 epoch 与重复度。
7. **分词与打包**：统计 token 膨胀、padding、文档拼接和跨文档 attention。
8. **版本化**：让每个训练 checkpoint 能追溯到精确数据快照与转换代码。

## 数据混合

设数据源 $i$ 的采样概率为 $p_i$。简单按语料大小采样会让高资源域主导；温度采样可写为：

$$
p_i=\frac{n_i^\alpha}{\sum_j n_j^\alpha},\quad 0<\alpha\le 1
$$

$\alpha<1$ 提高小数据源权重，但也可能导致过拟合和重复记忆。配比必须结合验证集、梯度信号和下游目标迭代。

## 关键风险

- 解析错误会系统性制造重复页眉、乱码与断句。
- 质量模型可能偏好自身风格，压低少数语言和非主流表达。
- 去重阈值过强会删掉合理模板与相似代码，过弱则增加记忆和污染。
- 合成数据会继承生成器偏差；缺少来源标签时难以回滚。
- benchmark 题目或答案进入训练集后，分数不再代表泛化。
